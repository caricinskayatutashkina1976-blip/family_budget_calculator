# Калькулятор семейного бюджета

Учебный одностраничный калькулятор на HTML, CSS и JavaScript: один файл `index.html`, без фреймворков и без подключения внешних библиотек.

## Возможности

- считает доходы;
- считает расходы;
- показывает остаток;
- анализирует финансовый статус;
- поддерживает светлую и тёмную тему.

## Как запустить

Откройте файл `index.html` в браузере (двойной щелчок или перетаскивание в окно браузера). Для работы интернет не нужен.
